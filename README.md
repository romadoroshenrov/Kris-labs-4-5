# Материалы лабораторных работ №1–5

В архиве пользователя были презентация и документы о голосовом ассистенте «Кристал», но не исходный проект. Лабораторные №1–3 посвящены его документации. Лабораторные №4–5 выполняются на исходном коде открытой программы ripgrep, как допускают методические указания А. А. Гребенькова.

В корне репозитория остался **отдельный учебный модуль** сопоставления четырёх голосовых команд с действиями. Он был подготовлен до выбора открытого проекта, не является исходным кодом полного ассистента и не служит основой окончательных отчётов №4–5.

Пять отчётов в формате DOCX находятся в каталоге `reports/`. Они оформлены по предоставленным образцам Ионова. В работах №1–3 описаны требования, методика испытаний и руководство оператора; испытания полного приложения не заявлены как проведённые.

Для лабораторных №4–5 используется также исходный код открытого проекта [ripgrep](https://github.com/BurntSushi/ripgrep) в каталоге `ripgrep/`. Исходное состояние взято из коммита `91f5d22ef48bde459d90a8c7dbeab416e97d0f2b`; лицензии проекта сохранены. Сборка и тесты выполняются в каталоге `ripgrep/`.

```powershell
cd ripgrep
cargo test -p grep-cli
cargo build --bin rg
```

## Проверка учебного модуля

```powershell
cargo test
cargo build
```

## История учебного модуля

Коммиты `e0d9618` и `42120d6` содержат исходный и переработанный варианты модуля. Разницу можно увидеть командой `git diff e0d9618 42120d6 -- src/lib.rs`.

Для окончательных лабораторных №4–5 сравнивайте коммиты `d413719` и `fdc7787` в каталоге `ripgrep/`.

## Чтобы продолжить с исходным проектом

Добавить настоящий репозиторий или архив с `Cargo.toml`, `crates/`, `frontend/`, ресурсами и инструкцией по сборке. После этого рефакторинг следует перенести в реальные модули проекта, прогнать его тесты и заменить учебный пример в отчёте фактическими путями и результатами.
