# Kris command core — учебный модуль

Этот репозиторий создан для лабораторных работ №4–5 по методическим указаниям А. А. Гребенькова. В приложенном архиве были только презентация и документы о голосовом ассистенте «Кристал»; исходного проекта там не было. Поэтому здесь находится **отдельный учебный модуль**, реализующий сопоставление четырёх голосовых команд с действиями. Он не является исходным кодом полного ассистента и не выполняет системных операций.

## Проверка

```powershell
cargo test
cargo build
```

## История для лабораторных

Первый коммит содержит исходный вариант. Второй коммит содержит рефакторинг без изменения результатов функции `resolve`. Разницу можно увидеть командой `git diff HEAD~1 HEAD -- src/lib.rs`.

## Чтобы продолжить с исходным проектом

Добавить настоящий репозиторий или архив с `Cargo.toml`, `crates/`, `frontend/`, ресурсами и инструкцией по сборке. После этого рефакторинг следует перенести в реальные модули проекта, прогнать его тесты и заменить учебный пример в отчёте фактическими путями и результатами.
